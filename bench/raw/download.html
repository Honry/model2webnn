Download throughput of a package running

URL parameters: package=../packages/qwen3-4b-pkg-i8/ (or an absolute URL, e.g. a package hosted on Hugging Face / a CDN), windows=1,2,4,8 (files in flight at once), segments=1,4 (byte ranges per big file), limitMB=600 (stop adding files after this many MB), repeat=1. Every combination downloads the same files with the HTTP cache bypassed.
